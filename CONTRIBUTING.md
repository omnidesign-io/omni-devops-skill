# Contributing

This repository is a home for evolving Omni Design's Cloudflare-first DevOps workflow as the process improves.

Prefer small, practical updates that make future project setup safer or easier to repeat. When adding knowledge, keep `SKILL.md` focused on the core workflow and move longer examples, templates, or detailed checklists into reference files or scripts.

Before releasing a change, validate that `SKILL.md` still has valid frontmatter and that the README accurately describes when the skill should be used.
